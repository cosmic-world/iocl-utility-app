TT Crew Temporary Pass

User Manual

This application is used to submit temporary pass requests for TT crew members and to review existing requests.

1. Before you begin

  • Confirm that the correct location is shown in the form.
  • Keep the crew member's mobile number, government ID, and licence details ready.
  • Use the same spelling for Vendor, Crew Name, and TT No as the supporting records whenever possible.
  • Users can submit requests; authorized users can approve daily attendance for an existing request. Master Data is available to administrators.

2. Start a request

  1. Open TT Crew Temporary Pass from Application Selection.
  2. Select the Crew Type: Driver or Helper. The licence number is required for Drivers and disabled for Helpers.
  3. Select an existing Vendor or type a new Vendor name.
  4. Select or type the Crew Name. Suggestions depend on the selected Vendor.
  5. Select or type the TT No. Spaces are removed automatically.
  6. Enter a 10-digit Mobile No and the ID Proof No.
  7. Select Request From and Request To dates. The end date must be the same as or later than the start date.

3. Upload documents

Upload a PDF or image up to 30 MB for each applicable document:

  • Request Letter
  • ID Proof
  • Driving Licence Front
  • Driving Licence Back
  • Additional Doc

Use Choose File to select a file from the device, or the camera button to capture an image. The file name appears below each button. Replace a selected file by choosing another file in the same slot.

4. Submit and check requests

  1. Review the dates, identity numbers, and document names.
  2. Select SUBMIT once and wait for the success message. Do not refresh while the loader is visible.
  3. If the same TT crew already has a pending request, the application will stop the submission. Use the Existing Request table instead.
  4. Search by Vendor or TT No, then select SEARCH RECORDS.
  5. Select the visibility icon in a document column to open an uploaded document. No icon means no document was saved for that record.
  6. Select CLEAR VIEW to reset the search table.

5. Dashboard and approvals

Open Temporary Pass Dashboard to review active requests. Authorized users can select Approve Today once per day for an eligible request. A request may be approved on multiple dates, but the same date cannot be recorded twice. The approval history shows both the total days and the recorded dates.

6. Master data

Administrators can open TT Crew Master Data to review the crew information used by the form suggestions. When a new Vendor or crew member is entered, the application can save the master record after a successful request.

7. Common issues

  • Use exactly 10 digits for Mobile No.
  • All required fields must be completed before submission.
  • Only PDF, PNG, JPEG, JPG, and WEBP files up to 30 MB are accepted.
  • Use a clear image and avoid rotating or cropping out ID details.
  • If a document is missing, upload it again and submit the request.
  • If a duplicate request warning appears, search the Existing Request table and request today's approval instead.
