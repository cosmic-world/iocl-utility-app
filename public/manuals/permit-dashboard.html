Permit Dashboard

User Manual

This application displays permit and clearance information received from the configured permit mailbox and provides tools for submitting and maintaining permit records.

1. Before you begin

  • Select the correct terminal and confirm its name in the header.
  • Make sure the application can reach the configured permit mailbox and data service.
  • Users can view and refresh permit data. Authorized administrators can modify records and maintain configuration-dependent data.

2. View permit data

  1. Open Permit Dashboard from Application Selection.
  2. Select Permit Table View to see active permit records for the selected terminal.
  3. Review the permit number, permit type, contractor, work description, location, officer, and clearance times.
  4. Use Extract Data from Mail when you need to refresh permit information immediately. The application also refreshes data automatically.
  5. Use Permit Layout View on a desktop screen for the visual display layout. The layout automatically cycles through the available records.

3. Submit a permit request

  1. Select Permit Request Form.
  2. Enter the location and contractor details exactly as used in the permit request.
  3. Enter the work description and work location clearly enough for the reviewing officer to identify the job.
  4. Select the permit type and enter the receiver/requestor name.
  5. Enter valid Clearance From and Clearance Till times. Check that the clearance period covers the intended work.
  6. Review all details carefully, then submit the form.
  7. Return to Permit Table View and refresh the mailbox data to confirm the record.

4. Modify records

Authorized administrators can open Modify Permit Records to edit or manage permit data. Regular users should contact an administrator when a correction is needed.

5. Understanding the table

  • Permit Type: category of work such as hot, cold, electrical, or height work.
  • Permit No: unique reference number from the permit request. Use it when discussing a record with the control room or administrator.
  • Work Description / Location: the approved activity and place of work.
  • Clearance From / Till: active clearance time window. A permit outside this window may no longer be active.
  • Officer Name: officer associated with the permit record.

6. Common issues

  • Confirm the correct terminal was selected before reviewing data.
  • Use Extract Data from Mail if a newly received permit is not visible, then allow the table to refresh.
  • Check the permit number and clearance times against the source mailbox message.
  • Permit Layout View is intended for desktop screens.
  • Contact an administrator if the mailbox data, permit details, or officer mapping is incorrect.
