Worker Entry

User Manual

This application is used to submit worker entry requests, manage worker and contractor master data, and process pass approvals.

1. User roles and preparation

  • Request users create worker entry requests and monitor their status.
  • Approving users review pending requests and approve or reject selected workers.
  • Administrators maintain worker, contractor, and officer master data.
  • Before submitting, keep the worker's full name, mobile number, government ID, address, purpose, entry time, contractor, and approving officer details ready.

2. Submit a worker entry request

  1. Open Worker Entry from Application Dashboard.
  2. Open Worker Entry Request.
  3. Select or enter the location and contractor. Existing master data appears as suggestions.
  4. Add each worker and enter the full name, mobile number, ID proof number, and address carefully.
  5. Enter the work purpose and requested entry time. Use a clear, specific purpose.
  6. Select the approving officer and verify the displayed officer details.
  7. Review every worker in the request before submitting.
  8. Submit the request and wait for confirmation. Avoid submitting the same request repeatedly while it is processing.
  9. Use the forwarding option when the request must be sent to another approving officer, if available.

3. Approval Centre

  1. Open APPROVAL CENTRE to view pending worker requests.
  2. Open a request and compare the worker, contractor, purpose, location, and requested time with the supporting information.
  3. Approved workers can receive a gate pass according to the site's process. Rejected workers must be corrected and submitted again if entry is still required.

4. Approval history

Open APPROVAL HISTORY to search and review previously processed requests. Use the date, location, and contractor filters to narrow the results. Check the final status before treating a worker as approved.

5. Master data

Worker Master Data stores reusable worker details. Contractor Master Data stores contractor details. Authorized administrators should add, correct, or remove outdated entries so request forms provide accurate suggestions. Master data changes do not replace the need to review each new request.

6. Common issues

  • Complete all required worker and request fields before submitting.
  • Verify the selected approving officer and email address.
  • Use the correct location and contractor when searching approval history.
  • If a worker or contractor is missing, ask an administrator to update master data.
  • If a request remains pending, contact the selected approving officer rather than creating duplicate requests.
  • Confirm the final approval status before issuing or allowing entry with a gate pass.
